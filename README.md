A simple event management system built using React and Redux Toolkit allowing users to view events and manage their registrations. 

Steps to run:
1. Clone repo using git clone https://github.com/HumbalH/event-management-system.git
2. open the project folder event-management-system
3. run npm install to install needed dependencies
4. Get API key from TicketMaster and add it to your env file
5. run npm run dev to launch the website
